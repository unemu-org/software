freedos-comp - licence index

Our original index prose is dedicated to the public domain under CC0-1.0.
Quoted upstream notices and licence texts retain their own copyrights.
This is an independent index, not a FreeDOS Project document.

The floppy holds only COMP.ZIP, the complete official package ZIP,
unmodified. Copy the ZIP to a hard disk or use it with FreeDOS
FDINST/FDIMPLES. LICENSES.TXT is a separate media-set extra.
The source extra SOURCE.ZIP is the same complete package ZIP, including
its SOURCE/ tree; the medium links to that exact source attachment.
No package program or build script was executed.

Evidence convention: !/ separates an inner SOURCE ZIP from its member.
Line numbers are one-based after decoding the original text and splitting
LF/CRLF lines. The copying-policy field is a summary: source headers
supply the precise version, or-later option, and bundled library grants.
GPL Version 2 metadata without "only" agrees with an explicit GPL2+
source grant. A different stated base version is excluded.
First-party helper files belong to their program grant; independently
licensed components are named below. This is not a claim that every
source file repeats the program notice. No licence is inferred from
a generic Freeware/Open source declaration.
